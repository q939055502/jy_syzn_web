检测指南管理系统使用指南
系统概述
本系统主要实现检测指南后台管理录入与对外展示两大核心功能，核心围绕分类 - 检测对象 - 检测项目 - 检测参数四层严格层级关系进行数据管理，检评规范、委托单模板仅与检测参数建立多对多关联关系。系统前台展示的指南以带水印、噪点的图片形式呈现，具备防爬功能，且支持电脑、平板、手机多设备适配；后台支持核心数据的增删改查、禁用 / 启用，以及用户权限基础管理（角色管理、权限管理、系统设置功能暂未完成）。
适用角色
后台管理员：负责分类、检测对象、检测项目、检测参数、检评规范、委托单模板的全量数据维护，以及用户管理操作；
前台访客：通过层级筛选或搜索查看检测指南、下载对应委托单，可在电脑、平板、手机等设备上操作使用。
第一部分 后台管理端操作
后台管理端为系统数据维护核心入口，所有前台展示的指南数据均由后台录入配置，操作需遵循层级关联、级联禁用 / 启用、关联防删的核心规则。
1.1 核心层级数据管理（分类→检测对象→检测项目→检测参数）
四层数据严格遵循上级创建后才可创建下级的规则，均支持增、删、改、查、禁用 / 启用操作，核心约束统一，各节点专属操作如下。
通用操作规则
禁用：禁用上级节点，其包含的所有下级节点将自动同步禁用；
启用：启用下级节点，其所属的所有上级节点将自动同步启用；
删除：节点若被关联 / 使用（如下级已创建、与检评规范 / 委托单模板关联等），则无法删除，删除操作会触发失败提示，需先解除所有关联后再尝试删除；
查改：支持单条数据查看、编辑，修改后前台展示内容将同步更新。
1.1.1 分类管理
分类为系统数据最顶层节点，无上级关联，是检测对象的创建基础。
新增：填写分类名称、备注等基础信息，提交后完成创建；
删改查 / 禁用：遵循通用操作规则，删除前需确认所有下属检测对象已删除 / 解除关联。
1.1.2 检测对象管理
检测对象隶属于分类，创建时必须选择所属分类，为检测项目的创建基础。
新增：选择所属分类，填写检测对象名称、基础属性、备注等信息，提交后完成创建；
删改查 / 禁用：遵循通用操作规则，禁用后下属所有检测项目、检测参数自动禁用；删除前需删除所有下属检测项目或解除关联。
1.1.3 检测项目管理
检测项目隶属于检测对象，创建时必须选择所属检测对象（将自动关联至对应分类），为检测参数的创建基础。
新增：选择所属检测对象，填写检测项目名称、核心属性、备注等信息，提交后完成创建；
删改查 / 禁用：遵循通用操作规则，禁用后下属所有检测参数自动禁用；删除前需删除所有下属检测参数或解除关联。
1.1.4 检测参数管理
检测参数为四层层级的最底层节点，创建时必须选择所属检测项目（将自动关联至对应检测对象、分类），是与检评规范、委托单模板建立关联的核心节点。
新增：①选择所属检测项目；②填写检测参数基础信息（含组批规格、取样频率、取样要求、送检要求、所需信息、备注等前台展示的核心内容）；③可选操作：关联合适的检评规范、选择对应的委托单模板；④提交后完成创建；
编辑：可修改基础信息，也可新增 / 解除与检评规范、委托单模板的关联关系；
删改查 / 禁用：遵循通用操作规则，删除前需解除与检评规范、委托单模板的所有关联。
1.2 检评规范管理
检评规范仅与检测参数建立多对多关联，支持独立的增删改查，关联 / 解除关联操作在检测参数的新增 / 编辑页面完成。
新增 / 编辑：填写检评规范名称、编号、核心内容等信息，提交后完成维护；
查看：可查看所有检评规范的基础信息，以及被哪些检测参数关联使用；
删除 / 禁用：删除前需确认未被任何检测参数关联，禁用后所有关联的检测参数中将隐藏该检评规范。
1.3 委托单模板管理
委托单模板为文件类数据，仅与检测参数建立多对多关联，支持增删改查、查看使用情况、文件下载 / 更新，关联操作在检测参数新增 / 编辑页面完成。
新增：上传委托单模板文件（如 Word、PDF），填写模板名称、适用场景等信息，提交后完成创建；
编辑 / 更新：可修改模板基础信息，也可重新上传文件完成模板更新，更新后所有关联的检测参数将同步使用新模板；
查看使用情况：点击对应模板的「查看使用」按钮，可查看该模板被哪些检测参数关联；
下载：可单独下载委托单模板原文件，用于本地编辑；
删除 / 禁用：删除前需确认未被任何检测参数关联，禁用后所有关联的检测参数中将隐藏该模板，前台无法下载。
1.4 用户管理
系统支持基础的用户管理功能，角色管理、权限管理模块暂未完成，当前可实现用户增删改查、启 / 禁用、角色权限分配（权限生效需等待后续模块开发完成）。
新增：填写用户账号、密码、姓名、联系方式等信息，分配所属角色，提交后完成创建；
启 / 禁用：禁用用户后，该账号将无法登录系统；启用后恢复登录权限；
编辑：可修改用户基础信息，重新分配角色；
删除：直接删除用户账号，删除后不可恢复，建议优先使用「禁用」功能。
第二部分 前台展示端操作
前台为检测指南的对外展示入口，无需登录，支持电脑、平板、手机多设备适配，适配不同屏幕尺寸，保障操作流畅性与查看清晰度；支持层级筛选和关键词搜索两种指南查询方式，所有指南均以图片形式展示，带水印、噪点防爬，支持委托单模板下载。
2.1 左侧侧边栏层级筛选
前台左侧侧边栏严格按照分类 - 检测对象 - 检测项目的层级展示，为核心的指南导航方式，操作步骤：
点击左侧某一分类，展开该分类下的所有检测对象；
点击某一检测对象，展开该对象下的所有检测项目；
点击某一检测项目，页面主体区域将展示该项目下所有检测参数对应的检测指南卡片。
2.2 右上角关键词搜索
支持精准 / 模糊搜索，搜索框可输入检评规范名称、检评规范编号、检测对象名称、检测参数名称作为关键词，操作：
点击右上角搜索框，输入关键词；
按下回车键 / 点击搜索图标，页面将展示所有匹配的检测指南卡片；
清空搜索框可恢复至侧边栏筛选的初始状态。
2.3 检测指南查看与委托单下载
指南展示：选中筛选 / 搜索结果后，页面主体以卡片形式展示检测指南，单张卡片包含完整信息：组批规格、取样频率、取样要求、送检要求、所需信息、检评规范、备注，所有信息均以带水印、噪点的图片呈现，多设备下均能清晰查看；
委托单下载：每张指南卡片的右上角设有「委托单下载」按钮，点击后可下载该检测参数关联的委托单模板文件，无关联模板时按钮将隐藏，多设备均支持下载操作。
第三部分 系统核心操作禁忌与注意事项
层级创建禁忌：未创建上级节点时，无法创建下级节点（如未建分类则无法建检测对象）；
禁用 / 启用级联：禁止单独启用下级节点而保留上级禁用状态，系统将自动启用上级；禁用上级前需确认下属所有节点无需使用；
删除约束：所有节点 / 检评规范 / 委托单模板，若存在关联 / 使用关系，必须先手动解除所有关联，否则删除失败并触发提示；
数据同步：后台修改（如检测参数信息、委托单模板更新）后，前台展示内容将实时同步，无需额外操作，多设备前台均会同步更新；
前台防爬：指南图片的水印、噪点为系统默认设置，不支持前台关闭 / 修改；
多设备适配：前台兼容电脑、平板、手机，无需单独适配，若出现展示异常，可刷新页面或切换浏览器尝试；
未完成功能：角色管理、权限管理、系统设置模块暂未开发，当前用户分配的角色权限暂不生效，所有后台账号均为管理员权限。
第四部分 常见问题解答
Q1：删除分类 / 检测对象 / 检测项目时提示删除失败，如何处理？
A：先检查该节点是否有下属节点（如分类下有检测对象、检测项目下有检测参数），或是否被其他模块关联，删除所有下属节点 / 解除所有关联后，重新尝试删除即可。
Q2：禁用检测参数后，如何恢复使用？
A：直接点击该检测参数的「启用」按钮，系统将自动检查其所属的检测项目、检测对象、分类，若上级被禁用，将同步启用所有上级节点，恢复后前台可正常查看，多设备均同步生效。
Q3：如何查看某份委托单模板被哪些检测参数使用？
A：进入后台「委托单模板管理」，找到对应模板，点击「查看使用情况」按钮，即可查看所有关联的检测参数名称、所属检测项目 / 对象 / 分类。
Q4：前台搜索关键词后，无匹配的指南结果，可能原因是什么？
A：①关键词输入错误（如检评规范编号、检测对象名称错别字）；②对应的检测参数 / 检评规范被后台禁用；③该关键词对应的内容尚未在后台创建录入；④若在移动设备上搜索无结果，可切换至电脑端尝试，排除设备浏览器兼容问题。
Q5：后台编辑了检测参数的取样要求，前台为何未更新？
A：先检查后台是否完成「提交」操作，若已提交仍未更新，可刷新前台页面，若仍无变化，确认该检测参数未被禁用（禁用状态的参数前台不展示）；多设备前台均未更新时，可等待 1-2 分钟再次刷新，排查网络同步延迟问题。
Q6：移动设备（手机 / 平板）查看前台指南时展示异常，如何处理？
A：①尝试刷新页面，清除浏览器缓存；②切换至主流浏览器（如 Chrome、微信内置浏览器）；③若仍异常，可切换至电脑端查看，同时联系管理员排查系统适配问题
