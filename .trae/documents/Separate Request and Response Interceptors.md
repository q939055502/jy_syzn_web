## 分离请求和响应拦截器

### 目标
将 `src/api/request.js` 中的请求和响应拦截器分离到独立文件中，提高代码的可维护性和模块化程度。

### 步骤
1. **创建拦截器目录**：在 `src/api` 下创建 `interceptors` 目录
2. **创建请求拦截器文件**：
   - 文件路径：`src/api/interceptors/request.js`
   - 内容：将当前 `request.js` 中的请求拦截器逻辑迁移到该文件
   - 导出请求拦截器和请求拦截器错误处理函数
3. **创建响应拦截器文件**：
   - 文件路径：`src/api/interceptors/response.js`
   - 内容：将当前 `request.js` 中的响应拦截器逻辑迁移到该文件
   - 导出响应拦截器和响应拦截器错误处理函数
4. **更新 request.js 文件**：
   - 删除文件中直接定义的拦截器
   - 从新创建的拦截器文件中导入请求和响应拦截器
   - 将导入的拦截器附加到 axios 实例上
5. **验证更改**：确保 `src/api/user.js` 等依赖文件仍能正常工作

### 预期结果
- 请求和响应拦截器逻辑分离到独立文件，提高代码模块化
- 保持现有功能不变，所有 API 请求仍能正常工作
- 便于后续对拦截器逻辑进行单独维护和扩展

### 代码结构变更
```
src/api/
├── request.js          # axios 实例创建和拦截器配置
├── user.js             # 用户相关 API
└── interceptors/       # 新增拦截器目录
    ├── request.js      # 请求拦截器
    └── response.js     # 响应拦截器
```
