# 修复 `ReferenceError: useUserStore is not defined` 错误

## 问题分析

从搜索结果和文件内容来看，有两个文件仍然在使用 `useUserStore`，导致出现 `ReferenceError: useUserStore is not defined` 错误：

1. `src/views/login/Login.vue` - 第15行导入了 `useUserStore`，第18行使用了它
2. `src/components/UserInfo.vue` - 第50行导入了 `useAuthStore`，但第63行仍然使用了 `useUserStore()`，这是一个不一致的地方

## 修复方案

### 1. 修复 `src/views/login/Login.vue`

移除 `useUserStore` 的导入和使用，因为这个组件只是一个容器，它包含了 `LoginForm.vue` 组件，而 `LoginForm.vue` 已经被更新为使用 `useAuthStore` 了。

### 2. 修复 `src/components/UserInfo.vue`

将第63行的 `useUserStore()` 改为 `useAuthStore()`，保持与导入的一致性。

## 修复步骤

1. 编辑 `src/views/login/Login.vue` 文件：
   - 移除第15行的 `useUserStore` 导入
   - 移除第18行的 `useUserStore()` 使用

2. 编辑 `src/components/UserInfo.vue` 文件：
   - 将第63行的 `const userStore = useUserStore();` 改为 `const userStore = useAuthStore();`

3. 重启开发服务器，确保修改后的代码生效

4. 检查浏览器控制台，确认错误已被解决

## 预期效果

修复后，所有文件都将使用正确的 `useAuthStore` 或 `useUserManagementStore`，不再引用已过时的 `useUserStore`，从而解决 `ReferenceError: useUserStore is not defined` 错误。
