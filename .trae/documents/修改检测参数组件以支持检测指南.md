# 修改检测参数组件以支持检测指南

## 1. 需求分析
根据用户要求和后端文档，需要对检测参数相关组件进行以下修改：
- 在 `DetectionParam.vue` 中展示检测参数对应的检测指南信息
- 在 `DetectionParamForm.vue` 中添加检测指南单选配置
- 检测参数和检测指南是多对多关系，但表单中要求单选

## 2. 修改方案

### 2.1 修改 `DetectionParam.vue`
1. **添加检测指南列**：在表格中新增一列用于展示检测指南信息
2. **处理多个指南**：如果检测参数关联多个指南，只显示第一个或用逗号分隔
3. **展示关键信息**：显示检测指南的采样批次或报告时间等关键信息

### 2.2 修改 `DetectionParamForm.vue`
1. **添加指南选择字段**：新增一个检测指南选择字段，使用单选组件
2. **获取指南列表**：在组件挂载时获取所有可用的检测指南
3. **处理编辑模式**：在编辑模式下，根据当前检测参数的 `guide_ids` 设置选中的指南
4. **传递指南ID**：将选择的指南ID传递给后端，更新检测参数

## 3. 实现步骤

1. **在 `DetectionParamForm.vue` 中添加指南选择功能**
   - 引入检测指南状态管理
   - 在表单中添加单选组件
   - 处理指南列表的获取和选择

2. **更新 `DetectionParam.vue` 以展示指南信息**
   - 在表格中添加指南列
   - 格式化展示指南信息

3. **测试修改**
   - 验证表单中指南选择功能正常
   - 验证列表中指南信息正确显示

## 4. 技术要点

- 使用 Pinia 状态管理获取检测指南列表
- 处理检测参数和检测指南的多对多关系
- 确保表单提交时正确传递指南ID
- 优化指南信息的展示方式
