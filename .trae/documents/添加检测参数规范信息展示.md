## 实现计划

### 1. 分析需求

* 后端接口不再返回整个检评规范对象，只返回id、规范名称和规范代码

* 需要在检测参数页面展示规范信息

* 规范名称需添加中文书名号（如无）

* 规范名称和代码同一列，中间换行

### 2. 实现步骤

#### 2.1 修改表格结构

* 在 `DetectionParam.vue` 表格中添加「规范信息」列

* 位置建议：可放在「价格说明」列之后，「必检」列之前

#### 2.2 实现规范信息格式化

* 创建计算属性或方法，处理规范信息的格式化

* 为每个规范名称添加中文书名号

* 组合规范名称和代码，使用换行符分隔

* 处理多个规范的情况（用逗号分隔或其他方式）

#### 2.3 数据处理

* 确保 `filteredParams` 计算属性正确处理规范数据

* 验证数据结构，确保能正确访问 `standards` 数组

#### 2.4 模板实现

* 在新增列中使用自定义模板

* 调用格式化方法展示规范信息

* 确保样式美观，换行正确显示

### 3. 代码修改点

#### 3.1 表格列添加

```vue
<!-- 规范信息 -->
<el-table-column label="规范信息" min-width="15%">
  <template #default="scope">
    <div class="standard-info">{{ formatStandardInfo(scope.row.standards) }}</div>
  </template>
</el-table-column>
```

#### 3.2 格式化方法实现

```javascript
// 格式化规范信息
const formatStandardInfo = (standards) => {
  if (!standards || standards.length === 0) return '无';
  
  return standards.map(standard => {
    // 添加中文书名号
    let name = standard.standard_name;
    if (!/^《.*》$/.test(name)) {
      name = `《${name}》`;
    }
    // 组合名称和代码，换行分隔
    return `${name}\n${standard.standard_code}`;
  }).join(', ');
};
```

### 4. 样式调整

* 确保 `.standard-info` 类支持换行显示

* 调整列宽，确保规范信息完整显示

### 5. 测试验证

* 检查规范名称是否正确添加书名号

* 验证规范名称和代码是否换行显示

* 测试多个规范的情况

* 确保数据为空时显示正常

### 6. 预期效果

* 规范信息列显示格式：

  ```
  《通用硅酸盐水泥》
  GB 175-2023
  ```

* 多个规范时：

  ```
  《通用硅酸盐水泥》
  GB 175-2023, 《混凝土强度检验评定标准》
  GB/T 50
  ```
