# 委托单模板功能更新计划

## 1. 问题分析
根据更正后的后端接口说明，委托单模板的创建和更新接口发生了重大变化：
- 从 `application/json` 格式改为 `multipart/form-data` 格式
- 新增了文件上传功能，创建和更新模板时需要上传模板文件
- 对文件类型有限制：仅支持.doc、.docx、.xls、.xlsx

## 2. 修改范围
### 2.1 API 层 (`delegationFormTemplate.js`)
- 修改 `createDelegationFormTemplate` 函数，支持 `multipart/form-data` 格式和文件上传
- 修改 `updateDelegationFormTemplate` 函数，支持 `multipart/form-data` 格式和文件上传

### 2.2 Service 层 (`delegationFormTemplateService.js`)
- 修改 `createDelegationFormTemplate` 函数，处理文件上传逻辑
- 修改 `updateDelegationFormTemplate` 函数，处理文件上传逻辑

### 2.3 Form 组件 (`DelegationFormTemplateForm.vue`)
- 修改表单，添加文件上传控件
- 修改表单提交逻辑，支持文件上传
- 恢复文件类型选择，并限制为指定格式
- 确保表单数据正确转换为 `multipart/form-data` 格式

### 2.4 其他文件
- 列表页面 (`DelegationFormTemplate.vue`)：保持不变
- Store 层 (`delegationFormTemplate.js`)：保持不变

## 3. 具体修改内容

### 3.1 API 层修改
- 将创建和更新接口的 Content-Type 设置为 `multipart/form-data`
- 支持文件上传，将文件数据作为 FormData 的一部分发送

### 3.2 Service 层修改
- 修改创建和更新模板的函数，处理文件上传逻辑
- 确保正确处理响应数据

### 3.3 Form 组件修改
- 添加文件上传控件，使用 Element Plus 的 `el-upload` 组件
- 修改表单数据模型，添加 `file` 字段
- 修改表单验证规则，添加文件上传验证
- 修改表单提交逻辑，将表单数据转换为 FormData 格式
- 恢复文件类型选择，但限制为指定格式（.doc、.docx、.xls、.xlsx）
