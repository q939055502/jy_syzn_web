# 令牌刷新格式修复计划

## 修复目标
修正刷新令牌请求格式，确保直接发送refreshToken字符串，而不是JSON对象，以符合后端API要求。

## 修复内容

### 1. 修改 `src/api/user.js`
- 修改 `refreshToken` API，将refreshToken直接作为字符串发送，而不是JSON对象

### 2. 修改 `src/api/interceptors/response.js`
- 修改 `refreshToken` 函数，直接发送refreshToken字符串，而不是JSON对象

## 实施步骤

1. 修改 `src/api/user.js` 中的 `refreshToken` API
2. 修改 `src/api/interceptors/response.js` 中的 `refreshToken` 函数
3. 测试修复效果

## 预期效果
- 刷新令牌请求格式正确
- 后端能正确处理刷新令牌请求
- 成功获取新的访问令牌
- 无缝的用户体验
