## 检测指南页面修复计划

### 1. 修复下载功能
- **问题**：检测指南页面的委托单模板下载功能不工作
- **原因**：下载链接处理方式不正确
- **解决方案**：
  - 检查并修复 `DetectionGuide.vue` 中的 `handleTemplateDownload` 函数
  - 参考 `DetectionParam.vue` 和 `DelegationFormTemplate.vue` 的下载实现
  - 确保下载链接完整，必要时添加 `window.location.origin`

### 2. 改进响应式设计
- **问题**：平板设备上检测指南没有居中显示，三端适配不完善
- **解决方案**：
  - 优化 `DetectionGuide.vue` 的布局，确保在平板设备上居中显示
  - 为不同设备尺寸添加适当的CSS断点
  - 实现图片在平板和手机上固定横向展示
  - 使用CSS Grid和Flexbox结合实现灵活布局

### 3. 调整DetectionItem.vue图片容器
- **问题**：图片容器需要实现"容器限缩 + 内容自适应 + 滚动条"
- **解决方案**：
  - 调整图片容器样式，设置固定高度
  - 实现内容自适应缩放
  - 添加滚动条支持

### 4. 集成新的API端点
- **问题**：当前使用多个API端点获取数据，效率较低
- **解决方案**：
  - 使用 `getCategoriesWithObjects` 替代当前的对象加载方式
  - 优化数据加载逻辑，减少API调用
  - 实现一次性获取所有分类和检测对象

### 5. 优化图片展示
- **问题**：图片展示需要铺满父容器，减少空白
- **解决方案**：
  - 调整图片容器与父容器的间距
  - 优化图片缩放逻辑
  - 确保图片完整展示

### 实施步骤
1. 首先修复 `DetectionGuide.vue` 的下载功能
2. 然后改进响应式设计，确保三端适配
3. 接着调整 `DetectionItem.vue` 的图片容器
4. 最后集成新的API端点，优化数据加载
5. 测试所有功能，确保正常工作

### 预期效果
- 检测指南页面在PC、平板、手机上均能正常显示
- 平板和手机上图片固定横向展示
- 下载功能正常工作
- 图片容器实现"容器限缩 + 内容自适应 + 滚动条"
- 使用新的API端点，提高数据加载效率
