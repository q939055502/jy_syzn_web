# 令牌刷新机制优化计划

## 优化目标
实现令牌自动刷新机制，当访问令牌过期时，使用刷新令牌获取新的访问令牌，确保用户无需重新登录，提供无缝的用户体验。

## 优化方案

### 1. 修改登录相关逻辑
- **保存 refresh_token**：修改 `userService.js` 中的登录逻辑，确保返回 `refresh_token`
- **添加 refresh_token 状态管理**：在 `stores/user.js` 中添加 `refreshToken` 状态，并从本地存储加载和保存

### 2. 添加刷新令牌 API
- **新增 refreshToken API**：在 `api/user.js` 中添加刷新令牌的 API 调用
- **新增 refreshToken 服务方法**：在 `userService.js` 中添加刷新令牌的服务方法

### 3. 实现令牌刷新机制
- **优化响应拦截器**：在 `responseInterceptorError` 中添加 401 错误处理，实现令牌刷新逻辑
- **处理并发请求**：添加状态管理，防止并发请求重复刷新令牌
- **更新令牌存储**：刷新成功后，更新本地存储的令牌信息

## 实施步骤

1. 修改 `src/services/userService.js`，确保登录返回 refresh_token
2. 修改 `src/stores/user.js`，添加 refreshToken 状态管理
3. 修改 `src/api/user.js`，添加 refreshToken API
4. 修改 `src/api/interceptors/response.js`，实现令牌刷新机制
5. 测试令牌刷新功能，验证优化效果

## 预期效果
- 访问令牌过期时，自动使用刷新令牌获取新令牌
- 无需重新登录，提供无缝用户体验
- 正确处理并发请求情况下的令牌刷新
- 完整的令牌生命周期管理

## 技术要点
- 使用 refresh_token 获取新的 access_token
- 实现并发请求处理机制
- 自动更新本地存储的令牌信息
- 提供优雅的错误处理
