## 实现计划

### 1. 修改 DetectionItem.vue 组件

#### 1.1 在操作列添加两个新按钮
- 在操作按钮组中添加「生成」按钮，使用 primary 类型，plain 样式
- 在操作按钮组中添加「查看」按钮，使用 success 类型，plain 样式
- 确保按钮样式与现有按钮保持一致

#### 1.2 添加按钮点击事件处理函数
- 为「生成」按钮添加 `handleGenerateImage` 点击事件
- 为「查看」按钮添加 `handleViewImage` 点击事件

#### 1.3 实现事件处理函数
- **handleGenerateImage**: 
  - 调用后端 `/api/image/detection` 接口，传递 `item_id`、`item_name` 和默认 `device_type: 'pc'`
  - 显示生成结果的成功或失败提示
  - 使用 `ElMessage` 组件显示操作结果

- **handleViewImage**:
  - 根据检测项目ID构建图片URL：`/api/image/detection:{item_id}?device_type=pc`
  - 使用新窗口打开图片URL，方便用户查看和下载

### 2. 实现 API 调用

#### 2.1 在 detectionApi.js 中添加生成图片的 API 方法
- 添加 `generateDetectionImage` 函数，使用 POST 方法调用 `/api/image/detection` 接口
- 处理 API 响应，返回统一格式

### 3. 代码实现细节

#### 3.2 API 调用错误处理

#### 3.3 用户体验优化
- 添加加载状态提示
- 操作成功后显示清晰的提示信息
- 查看图片时使用新窗口打开，不影响当前页面操作
