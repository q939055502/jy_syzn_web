## 实现用户状态启用/禁用功能

### 1. 需求分析
- 根据更新后的API文档，需要实现用户状态的启用/禁用功能
- API端点为：`PATCH /api/admin/users/{user_id}/toggle-active?is_active=true`
- 当前实现使用的是PUT请求，需要更新为PATCH请求

### 2. 修改计划

#### 2.1 更新API层
- **文件**：`src/api/user.js`
- **修改内容**：
  - 将`updateUserStatus`函数的请求方法从PUT改为PATCH
  - 更新端点路径为`/admin/users/{userId}/toggle-active`
  - 将状态参数从请求体改为查询参数

### 3. 实现细节

#### 3.1 API层修改
```javascript
// 更新前
export const updateUserStatus = (userId, status) => {
  return apiClient.put(`/admin/users/${userId}`, {
    is_active: status
  });
};

// 更新后
export const updateUserStatus = (userId, status) => {
  return apiClient.patch(`/admin/users/${userId}/toggle-active?is_active=${status}`);
};
```
