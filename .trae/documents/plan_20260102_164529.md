# 统一UserForm.vue与UserManagement.vue的样式

## 1. 问题分析

当前UserForm.vue使用了默认的Element Plus样式，而UserManagement.vue使用了CSS变量来定义样式，导致两者的背景色和字体色不一致。我需要修改UserForm.vue，使其使用与UserManagement.vue相同的CSS变量，支持深色模式，并确保所有元素的样式保持一致。

## 2. 实现计划

### 2.1 修改UserForm.vue的样式

1. **添加主题设置状态**：导入useSettingStore，获取isDark状态
2. **使用CSS变量**：将UserForm.vue中的样式替换为与UserManagement.vue相同的CSS变量
3. **统一对话框样式**：修改el-dialog的样式，使其背景色和字体色与UserManagement.vue保持一致
4. **统一表单样式**：修改el-form、el-input、el-select等表单元素的样式
5. **统一按钮样式**：修改el-button的样式，使其与UserManagement.vue保持一致
6. **支持深色模式**：确保样式在深色模式下也能正常显示

### 2.2 具体修改内容

#### src/views/form/UserForm.vue
- 导入useSettingStore，获取isDark状态
- 修改style标签，添加CSS变量样式
- 使用:deep()选择器来修改Element Plus组件的样式
- 确保对话框、表单、输入框、按钮等元素的样式与UserManagement.vue保持一致

## 3. 技术要点

- Vue 3 + Composition API
- Element Plus UI组件库
- CSS变量
- 深色模式支持
- 组件样式覆盖
- 主题一致性

- 支持深色模式
- 所有表单元素和按钮的样式与UserManagement.vue保持一致
- 整体视觉效果统一，用户体验良好
