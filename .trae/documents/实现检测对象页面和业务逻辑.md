# 实现检测对象页面和业务逻辑

## 1. 实现目标
按照与委托单模板相同的逻辑，实现检测对象的完整CRUD功能，包括API层、Service层、Store层和View层。

## 2. 实现步骤

### 2.1 API层 - 创建检测对象接口文件
- **文件路径**：`src/api/detectionObject.js`
- **功能**：实现检测对象的CRUD接口，包括获取列表、获取单个、创建、更新、删除、启用和禁用功能
- **API路径**：
  - GET `/api/detection/objects` - 获取检测对象列表
  - GET `/api/detection/objects/{object_id}` - 获取单个检测对象
  - POST `/api/detection/objects` - 创建检测对象
  - PUT `/api/detection/objects/{object_id}` - 更新检测对象
  - DELETE `/api/detection/objects/{object_id}` - 删除检测对象
  - PATCH `/api/detection/objects/{object_id}/enable` - 启用检测对象
  - PATCH `/api/detection/objects/{object_id}/disable` - 禁用检测对象

### 2.2 Service层 - 实现业务逻辑
- **文件路径**：`src/services/detectionObjectService.js`
- **功能**：实现业务逻辑和错误处理，对API响应进行统一处理
- **实现要点**：
  - 调用API层方法
  - 统一处理错误响应
  - 格式化返回数据

### 2.3 Store层 - 实现状态管理
- **文件路径**：`src/stores/detectionObject.js`
- **功能**：使用Pinia实现检测对象的状态管理
- **状态管理**：
  - 检测对象列表
  - 总数量
  - 分页信息
  - 加载状态
  - 删除加载状态
  - 错误信息

### 2.4 View层 - 实现列表页面
- **文件路径**：`src/views/DetectionObject.vue`
- **功能**：实现检测对象列表页面
- **UI组件**：
  - 搜索功能
  - 表格展示
  - 新增/编辑/删除操作
  - 状态切换
  - 分页功能（隐藏）

### 2.5 View层 - 实现表单页面
- **文件路径**：`src/views/form/DetectionObjectForm.vue`
- **功能**：实现检测对象新增编辑表单
- **表单字段**：
  - 对象名称
  - 对象代码
  - 对象类型
  - 所属分类
  - 描述
  - 状态
  - 备注

## 3. 技术要求
- **代码风格**：遵循现有代码风格
- **技术栈**：Vue 3 Composition API、Pinia、Element Plus
- **分层架构**：API层 → Service层 → Store层 → View层
