# 令牌刷新功能修正计划

## 修正目标
根据用户提供的正确文档，修正刷新令牌功能，确保使用正确的API端点、请求格式和参数。

## 问题分析

### 之前的错误实现
- **错误的API端点**：使用了 `/api/auth/token` 而不是 `/api/auth/refresh`
- **错误的请求格式**：使用了 `application/x-www-form-urlencoded` 而不是 `application/json`
- **错误的参数格式**：使用了 `grant_type` 和 `refresh_token` 作为form参数，而不是JSON对象

### 正确的实现要求
- **正确的API端点**：POST `/api/auth/refresh`
- **正确的请求格式**：`application/json`
- **正确的请求体**：`{ "refresh_token": "你的刷新令牌" }`
- **正确的响应处理**：从响应中获取 `access_token` 和 `token_type`

## 修正方案

### 1. 修改 `src/api/user.js`
- 修改 `refreshToken` API，使用正确的端点和请求格式

### 2. 修改 `src/services/userService.js`
- 确保服务方法调用正确的API，并处理正确的响应格式

### 3. 修改 `src/api/interceptors/response.js`
- 修改 `refreshToken` 函数，使用正确的API端点、请求格式和参数

## 实施步骤

1. 修改 `src/api/user.js` 中的 `refreshToken` API
2. 修改 `src/services/userService.js` 中的 `refreshToken` 服务
3. 修改 `src/api/interceptors/response.js` 中的 `refreshToken` 函数
4. 测试修正后的令牌刷新功能

## 预期效果
- 令牌刷新请求使用正确的API端点和格式
- 成功获取新的访问令牌
- 保持无缝的用户体验
