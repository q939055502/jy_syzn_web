## 修复检测项目组所属分类不显示的问题

### 问题分析
1. 从浏览器控制台截图可以看到，API返回的检测项目组数据中：
   - 每个检测项目组都有`category_id`字段
   - 但没有嵌套的`category`对象，也没有`category_name`字段
   - 同时，`categories`数组是有数据的，包含了完整的分类信息

2. 组件模板中只尝试从`scope.row.category?.category_name`或`scope.row.category_name`获取分类名称，所以总是显示"未分类"

### 解决方案
1. 在`filteredGroups`计算属性中，为每个检测项目组添加`category_name`字段
2. 遍历`categories`数组，根据`category_id`匹配对应的分类名称
3. 将匹配到的分类名称添加到检测项目组对象中

### 修复步骤
1. 修改`DetectionGroup.vue`组件中的`filteredGroups`计算属性
2. 在返回结果之前，为每个检测项目组添加`category_name`字段
3. 遍历`categories`数组，根据`category_id`匹配对应的分类名称
4. 验证修复效果

### 预期结果
检测项目组列表中的"所属分类"列能够正确显示分类名称，不再全部显示"未分类"

### 代码修改
```javascript
// 过滤后的检测项目组列表（全量展示）
const filteredGroups = computed(() => {
  let result = [...groups.value];
  
  // 分类过滤
  if (selectedCategory.value) {
    result = result.filter(group => 
      group.category_id === selectedCategory.value
    );
  }
  
  // 搜索过滤
  if (searchText.value) {
    const search = searchText.value.toLowerCase();
    result = result.filter(group => 
      group.group_name?.toLowerCase().includes(search)
    );
  }
  
  // 为每个检测项目组添加category_name字段
  result = result.map(group => {
    // 查找对应的分类
    const category = categories.value.find(cat => cat.category_id === group.category_id);
    return {
      ...group,
      category_name: category?.category_name || '未分类'
    };
  });
  
  // 全量展示，不进行分页
  return result;
});
```

这个修复方案将确保检测项目组列表中的分类信息能够正确显示，解决了之前所有项目组都显示"未分类"的问题。
