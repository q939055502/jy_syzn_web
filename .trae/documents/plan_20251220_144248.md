### 问题分析
项目无法通过局域网IP访问，而只能通过localhost访问，这是因为 Vite 开发服务器默认只监听本地回环地址（127.0.0.1），不接受来自局域网其他设备的请求。

### 解决方案
修改 Vite 配置文件，将服务器的 host 选项设置为 '0.0.0.0'，这样开发服务器就会监听所有网络接口，允许来自局域网的访问。

### 具体修改
1. **修改文件**：`vite.config.js`
2. **添加配置**：在 `defineConfig` 中添加 `server.host` 选项
3. **配置值**：将 `host` 设置为 `'0.0.0.0'`

### 修改代码
```javascript
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

// https://vite.dev/config/
export default defineConfig({
  plugins: [vue()],
  server: {
    host: '0.0.0.0', // 允许通过局域网IP访问
  },
})
```

### 验证方法
1. 重启开发服务器
2. 查看终端输出，会显示类似 `Local: http://localhost:5173/` 和 `Network: http://192.168.x.x:5173/` 的信息
3. 在同一局域网的其他设备上，使用显示的 Network IP 地址访问项目

### 预期结果
修改后，项目将可以通过局域网IP地址访问，同时保持 localhost 访问正常。
