# 检测项目指南网站实现方案

## 1. 项目结构设计

创建独立的检测项目指南模块，包含以下目录结构：

```
src/detectionGuide/
├── components/          # 组件目录
│   ├── Sidebar.vue       # 左侧导航栏组件
│   ├── DetectionCard.vue # 检测项目卡片组件
│   └── ImageViewer.vue   # 图片查看器组件
├── composables/         # 组合式函数
│   ├── useSidebar.js      # 侧边栏状态管理
│   └── useImageViewer.js  # 图片查看器状态管理
├── mock/               # 模拟数据
│   └── data.js           # 检测项目模拟数据
└── views/              # 视图目录
    └── DetectionGuide.vue # 主视图组件
```

## 2. 核心功能实现

### 2.1 左侧导航栏
- 实现可折叠的左侧栏，通过左上角图标控制显示/隐藏
- 一级列表展示检测项目分类（如混凝土结构材料、墙体材料等）
- 二级列表展示分类下的检测对象
- 点击检测对象时，右侧主体区域加载对应检测项目卡片

### 2.2 检测项目卡片
- 采用网格布局展示检测项目卡片
- 卡片包含检测项目名称和浓缩图
- 点击卡片图片可放大查看

### 2.3 图片查看器
- 放大展示检测项目图片
- 左上角提供委托单下载按钮
- 支持关闭图片查看器

## 4. 技术栈与依赖

- Vue 3 + Composition API
- Element Plus（UI组件库）
- Vue Router（路由管理）

## 5. 实现步骤

1. 创建项目目录结构
2. 实现主视图布局
3. 开发左侧导航栏组件
4. 开发检测项目卡片组件
5. 开发图片查看器组件
6. 创建模拟数据
7. 集成组件并测试功能

## 6. 路由配置

在主路由中添加检测项目指南路由：

```javascript
// src/router/index.js
import DetectionGuide from '../detectionGuide/views/DetectionGuide.vue';

const routes = [
  // 现有路由...
  {
    path: '/detection-guide',
    name: 'DetectionGuide',
    component: DetectionGuide,
    meta: { title: '检测项目指南' }
  }
];
```

## 7. 预期效果

- 点击左上角图标可切换左侧栏显示/隐藏
- 左侧栏分类可展开/折叠，显示检测对象
- 点击检测对象显示对应的检测项目卡片
- 点击卡片图片可放大查看，左上角有委托单下载按钮
- 所有功能基于模拟数据运行，后续可无缝对接后端API

该方案将实现一个功能完整、结构清晰的检测项目指南网站，满足用户的展示需求。
