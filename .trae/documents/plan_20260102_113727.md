# 权限管理页面API兼容修改方案

## 问题分析
1. **API路径不一致**：当前实现使用 `/admin/permissions`，最新API为 `/api/admin/permissions`
2. **数据结构变化**：最新API的权限数据包含 `id`, `code`, `resource`, `action`, `scope`, `description`, `is_active` 等字段
3. **功能实现调整**：最新API没有提供资源、动作、范围的多级联动接口，只有完整的权限CRUD接口
4. **参数不一致**：列表接口支持 `skip` 和 `limit`，而非 `page` 和 `limit`

## 优化方案
1. **更新API调用**：调整所有API调用路径，添加 `/api` 前缀
2. **调整数据结构**：修改页面数据处理逻辑，适应最新API的数据结构
3. **重新设计功能**：基于最新API能力，实现完整的权限CRUD功能
4. **保持页面布局**：维持原有的五列布局（资源、动作、范围、描述、操作）
5. **实现权限管理功能**：包含权限的新增、编辑、删除、启用/禁用

## 具体实现
1. **修改权限服务和API层**：更新API路径和数据处理逻辑
2. **调整权限管理页面**：
   - 保持原有的表格布局
   - 实现基于最新API的权限CRUD功能
   - 支持权限的新增、编辑、删除、启用/禁用
   - 实现权限的批量操作
3. **优化用户体验**：
   - 添加加载状态
   - 完善错误处理
   - 优化表单验证

## 预期效果
- 页面布局保持不变，仍为五列结构
- 功能符合最新API能力，支持完整的权限CRUD
- API调用路径正确，与最新文档一致
- 页面交互流畅，用户体验良好

- `src/api/permission.js`：更新API路径
- `src/services/permissionService.js`：调整数据处理逻辑
- `src/stores/permission.js`：更新状态管理逻辑
- `src/views/PermissionManagement.vue`：调整页面实现
