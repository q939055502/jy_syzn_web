# 实现送样指南页面和业务逻辑

## 1. 需求分析
根据API文档和现有代码结构，需要实现送样指南（检测指南）页面，包含以下功能：
- 送样指南列表展示
- 新增送样指南
- 编辑送样指南
- 删除送样指南
- 搜索和过滤功能

## 2. 技术架构
- Vue 3 + Composition API
- Pinia 状态管理
- Element Plus UI 组件
- RESTful API 集成

## 3. 实现步骤

### 3.1 创建API层
- **文件**：`src/api/detectionGuide.js`
- **功能**：封装送样指南相关的API请求
- **接口**：
  - 获取送样指南列表
  - 获取单个送样指南
  - 创建送样指南
  - 更新送样指南
  - 删除送样指南

### 3.2 创建Service层
- **文件**：`src/services/detectionGuideService.js`
- **功能**：处理送样指南的业务逻辑，调用API层
- **方法**：
  - 获取送样指南列表
  - 获取单个送样指南
  - 创建送样指南
  - 更新送样指南
  - 删除送样指南

### 3.3 创建Store层
- **文件**：`src/stores/detectionGuide.js`
- **功能**：管理送样指南的状态
- **状态**：
  - 送样指南列表
  - 总记录数
  - 分页信息
  - 加载状态
  - 错误信息

### 3.4 创建表单组件
- **文件**：`src/views/form/DetectionGuideForm.vue`
