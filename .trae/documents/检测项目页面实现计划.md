# 检测项目页面实现计划

## 1. 功能需求
根据API文档和模型说明，实现检测项目页面，包含以下功能：
- 检测项目列表展示
- 按分类筛选
- 关键词搜索
- 新增检测项目
- 编辑检测项目
- 删除检测项目
- 状态切换（启用/禁用）

## 2. 实现步骤

### 2.1 创建API层
- 创建 `src/api/detectionItem.js` 文件
- 实现检测项目相关API请求：
  - `getDetectionItemList` - 获取检测项目列表
  - `getDetectionItem` - 获取单个检测项目
  - `createDetectionItem` - 创建检测项目
  - `updateDetectionItem` - 更新检测项目
  - `deleteDetectionItem` - 删除检测项目

### 2.2 创建服务层
- 创建 `src/services/detectionItemService.js` 文件
- 实现检测项目相关业务逻辑：
  - `getDetectionItemList` - 获取检测项目列表（处理响应格式）
  - `getDetectionItem` - 获取单个检测项目（处理响应格式）
  - `createDetectionItem` - 创建检测项目（处理响应格式）
  - `updateDetectionItem` - 更新检测项目（处理响应格式）
  - `deleteDetectionItem` - 删除检测项目（处理响应格式）

### 2.3 创建状态管理层
- 创建 `src/stores/detectionItem.js` 文件
- 实现检测项目状态管理：
  - 状态定义（itemList, totalItems, pagination, isLoading等）
  - Getters（获取状态）
  - Actions（操作状态）：
    - `fetchItemList` - 获取检测项目列表
    - `fetchItemById` - 获取单个检测项目
    - `createItem` - 创建检测项目
    - `updateItem` - 更新检测项目
    - `deleteItem` - 删除检测项目
    - `batchDeleteItems` - 批量删除检测项目
    - `updatePagination` - 更新分页信息

### 2.4 创建表单组件
- 创建 `src/views/form/DetectionItemForm.vue` 文件
- 实现检测项目新增/编辑表单：
  - 项目组选择
  - 材料名称输入
  - 检测项目名称输入
  - 价格输入
  - 单位选择
  - 样品单位选择
  - 必检标识选择
  - 常规参数标识选择
  - 排序号输入
  - 状态选择

### 2.5 实现主页面
- 修改 `src/views/DetectionItem.vue` 文件
- 实现检测项目列表页面：
  - 搜索和筛选区域（分类筛选、关键词搜索）
  - 检测项目列表表格
  - 操作按钮（新增、编辑、删除）
  - 状态切换开关
  - 分页组件（隐藏但保留状态管理）

## 3. 技术要点

### 3.1 代码风格
- 遵循现有项目的代码风格和命名规范
- 使用相同的组件库和样式
- 保持相同的代码结构和层次

### 3.2 数据流向
- 页面组件通过store获取数据
- store通过service层调用API
- service层处理业务逻辑和响应格式
- API层处理与后端的通信

### 3.3 组件交互
- 使用与现有页面相同的交互方式
- 保持相同的模态框、提示信息等UI组件
- 实现相同的搜索防抖功能

### 3.4 状态管理
- 使用Pinia进行状态管理
- 保持与现有store相同的结构和命名
- 实现相同的加载状态和错误处理

## 4. 预期效果
- 实现与现有页面风格一致的检测项目管理页面
- 支持检测项目的增删改查功能
- 支持按分类筛选和关键词搜索
- 支持状态切换（启用/禁用）
- 支持批量删除功能
