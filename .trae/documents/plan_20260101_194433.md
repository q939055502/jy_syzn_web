# 超级管理员列改为拥有角色列方案

## 问题分析
当前用户管理页面中，"超级管理员"列仅显示"是"或"否"，无法直观展示用户拥有的所有角色。根据用户数据结构，每个用户对象包含`roles`数组，存储了用户的角色信息。

## 优化方案
1. 将"超级管理员"列修改为"拥有角色"列
2. 遍历用户的`roles`数组，提取角色名称
3. 用顿号连接多个角色名称，显示在单元格中
4. 调整列宽以适应多个角色名称的显示

## 具体实现
- 修改 `UserManagement.vue` 文件中的超级管理员列（第59-63行）
- 列标题从"超级管理员"改为"拥有角色"
- 模板中遍历 `scope.row.roles` 数组，提取每个角色的 `name` 属性
- 使用 `join('、')` 方法将角色名称用顿号连接
- 调整列宽至合适大小

## 预期效果
- 列标题："拥有角色"
- 单元格内容：角色名称以顿号分隔，如"管理员、编辑"
- 宽度自适应，能显示多个角色名称
- 清晰展示每个用户拥有的所有角色
