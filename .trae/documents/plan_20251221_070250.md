# 登录功能实现计划

## 1. 问题分析

根据API文档，后端提供了完整的认证接口，包括获取Token、刷新Token、获取用户信息和注销登录。当前的登录流程需要重新实现，以对接后端API。

## 2. 解决方案

### 2.1 修改 API 层 (`src/api/user.js`)

- 实现与后端认证接口的对接
- 使用axios进行HTTP请求
- 根据API文档设置正确的请求方法、URL和请求格式
- 处理不同的响应格式

### 2.2 修改 Service 层 (`src/services/userService.js`)

- 调用API层获取数据
- 处理业务逻辑
- 格式化返回数据
- 添加错误处理

### 2.3 修改 Store 层 (`src/stores/user.js`)

- 使用Pinia管理状态
- 保存和管理token
- 处理登录、登出和获取用户信息的状态
- 将token保存到本地存储

### 2.4 修改 Login.vue

- 移除第20-34行的登录状态验证和跳转代码

## 3. 具体实现

### 3.1 API 层 (`src/api/user.js`)

- 安装并配置axios
- 实现获取Token接口（`/api/auth/token`）
- 实现获取用户信息接口（`/api/auth/me`）
- 实现注销登录接口（`/api/auth/logout`）

### 3.2 Service 层 (`src/services/userService.js`)

- 调用API层获取Token
- 使用Token获取用户信息
- 处理登录和登出逻辑
- 统一错误处理

### 3.3 Store 层 (`src/stores/user.js`)

- 管理token状态
- 管理用户信息状态
- 管理登录状态
- 保存token到本地存储

### 3.4 Login.vue

- 删除第20-34行的登录状态验证和跳转代码

## 4. 技术要点

- 使用axios进行HTTP请求
- 处理不同的请求格式（如 `application/x-www-form-urlencoded`）
- 实现JWT Token的管理
- 统一的错误处理
- 状态管理与本地存储

## 5. 预期结果

- 登录功能能够正常对接后端API
- 能够正确获取和管理Token
- 能够获取用户信息
- 能够正确登出
- Login.vue不再进行登录状态验证和跳转
