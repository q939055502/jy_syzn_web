# 分类管理与检测项目组关联调整计划

## 一、修改目标
根据API文档的更正，实现检测项目组与分类的关联，每个项目组有一个所属分类。

## 二、核心修改内容

### 1. 检测项目组表单组件修改
- **文件**: `src/views/form/DetectionGroupForm.vue`
  - 添加分类选择字段，使用下拉选择器展示分类列表
  - 表单数据中添加`category_id`字段
  - 引入分类服务获取分类列表
  - 表单验证规则中添加`category_id`的必填验证

### 2. 检测项目组列表页面修改
- **文件**: `src/views/DetectionGroup.vue`
  - 在表格中添加"所属分类"列，显示项目组关联的分类名称
  - 调整搜索功能，支持按分类搜索
  - 更新表格列配置，调整宽度和显示顺序

### 3. 检测项目组状态管理修改
- **文件**: `src/stores/detectionGroup.js`
  - 确保状态中包含`category_id`字段
  - 支持获取分类信息并关联到项目组

### 4. 检测项目组服务修改
- **文件**: `src/services/detectionGroupService.js`
  - 确保API调用中包含`category_id`字段
  - 处理后端返回的关联分类数据

### 5. 检测项目组API修改
- **文件**: `src/api/detectionGroup.js`
  - 确保API请求中包含`category_id`参数
  - 支持按分类筛选项目组

## 三、技术实现要点

1. **分类数据获取**：在表单组件中使用分类服务获取全部分类列表，用于下拉选择
2. **关联关系处理**：项目组数据中添加`category_id`字段，关联到分类的`category_id`
3. **数据展示优化**：列表中显示分类名称而非ID，提升用户体验
4. **表单验证**：添加`category_id`的必填验证，确保数据完整性
5. **搜索功能增强**：支持按项目组名称和分类进行搜索

## 四、预期效果

1. 项目组表单中可以选择所属分类
2. 项目组列表中显示每个项目组的所属分类
3. 支持按分类筛选项目组
4. 确保数据完整性和一致性
5. 提升用户体验，使分类和项目组的关系清晰可见

## 五、修改顺序

1. 先修改API和服务层，确保支持`category_id`字段
2. 然后修改表单组件，添加分类选择功能
3. 最后修改列表页面，添加分类列和搜索功能
4. 测试所有功能，确保正常工作

## 六、注意事项

1. 确保与后端API的格式完全匹配
2. 注意处理分类数据加载和错误情况
3. 保持代码风格一致
4. 确保现有功能不受影响
5. 测试各种边界情况
