# 检测规范状态切换功能实现计划

## 1. 功能需求
- 在 `DetectionStandard.vue` 页面中添加状态切换功能，类似于 `UserManagement.vue` 中的实现
- 使用后端新增的启用/禁用检测规范的接口
- 实现乐观更新，失败时回滚状态

## 2. 实现步骤

### 2.1 API层 - 添加启用/禁用接口
在 `src/api/detectionStandard.js` 中添加：
- `enableDetectionStandard` 方法：调用 PATCH /api/detection/standards/{standard_id}/enable 接口
- `disableDetectionStandard` 方法：调用 PATCH /api/detection/standards/{standard_id}/disable 接口

### 2.2 服务层 - 添加状态更新服务
在 `src/services/detectionStandardService.js` 中添加：
- `enableDetectionStandard` 方法：处理启用检测规范的业务逻辑
- `disableDetectionStandard` 方法：处理禁用检测规范的业务逻辑

### 2.3 状态层 - 添加状态更新actions
在 `src/stores/detectionStandard.js` 中添加：
- `enableStandard` 方法：调用服务层启用方法，更新本地状态
- `disableStandard` 方法：调用服务层禁用方法，更新本地状态

### 2.4 组件层 - 实现状态切换UI
在 `src/views/DetectionStandard.vue` 中：
- 修改状态列，使用 `el-switch` 组件替换原有文本显示
- 添加 `handleStatusChange` 方法，处理状态切换逻辑
- 实现乐观更新，失败时回滚状态

### 3.4 组件层实现
```vue
<!-- 状态列 -->
<el-table-column prop="status" label="状态" width="140">
  <template #default="scope">
    <div class="status-switch">
      <el-switch
        v-model="scope.row.status"
        active-color="#13ce66"
        inactive-color="#ff4949"
        @change="(newStatus) => handleStatusChange(scope.row, newStatus)"
      />
      <span class="status-text">{{ scope.row.status === 1 ? '启用' : '禁用' }}</span>
    </div>
  </template>
</el-table-column>
```

```javascript
// 处理状态变化
const handleStatusChange = async (standard, newStatus) => {
  const result = await standardStore.updateStandardStatus(standard.standard_id, newStatus);
  if (result) {
    ElMessage.success(`检测规范 ${standard.standard_name} 状态已更新为: ${newStatus ? '启用' : '禁用'}`);
  } else {
    ElMessage.error('检测规范状态更新失败');
    // 更新失败，恢复原来的状态
    standard.status = !newStatus;
  }
};
```

## 4. 技术要点
- 遵循现有的分层架构：API → 服务 → 状态 → 组件
- 实现乐观更新，提升用户体验
- 添加适当的错误处理，确保系统稳定性
- 保持代码风格与现有代码一致
- 使用Element Plus组件库提供的el-switch组件

## 5. 预期效果
- 检测规范列表中的状态列将显示开关按钮
- 点击开关可以切换检测规范的启用/禁用状态
- 状态切换会立即更新UI，并调用后端API
- API调用失败时，UI会回滚到原来的状态
- 操作成功或失败会显示相应的提示信息
