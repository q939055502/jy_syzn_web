### 修复登录成功后空白页和刷新后跳登录页问题

1. **路由配置问题**
   * 路由配置中没有使用 Layout 组件作为父组件，直接将 HomeView 组件作为根路径组件
   * 修复方法：修改路由配置，使用 Layout 组件作为父组件，将 HomeView 组件作为子组件

2. **用户状态管理问题**
   * 页面刷新后，isLoggedIn 状态不会自动更新为 true，因为 state 初始化时只从 localStorage 获取了 token，没有根据 token 是否存在来更新 isLoggedIn 状态
   * 修复方法：修改 user store，在 state 初始化时，根据 token 是否存在来更新 isLoggedIn 状态

3. **导航守卫问题**
   * 导航守卫在检查登录状态时，只检查了 isLoggedIn 状态，没有检查 token 是否存在
   * 修复方法：修改导航守卫，在检查登录状态时，同时检查 token 是否存在

### 具体实现步骤

1. **修改路由配置**
   * 将 Layout 组件作为父组件，将 HomeView 组件作为子组件
   * 确保所有受保护的路由都使用 Layout 组件作为父组件

2. **修改 user store**
   * 在 state 初始化时，根据 token 是否存在来更新 isLoggedIn 状态
   * 确保在页面刷新后，isLoggedIn 状态能够正确反映用户的登录状态

3. **修改导航守卫**
   * 在检查登录状态时，同时检查 token 是否存在
   * 确保用户在页面刷新后，不会被错误地重定向到登录页面

### 预期效果

* 登录成功后，能够正确跳转到首页，显示完整的页面布局
* 页面刷新后，用户状态不会丢失，仍然保持登录状态
* 导航守卫能够正确检查用户的登录状态，只有未登录用户才会被重定向到登录页面
